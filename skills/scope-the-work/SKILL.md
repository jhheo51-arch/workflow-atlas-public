# 작업 범위 정리

1. 기존 결과물과 관련 지침을 읽고, 사용자가 바꾸려는 대상과 현재 동작을 확인합니다.
2. 사용자가 겪는 불편과 작업 후 할 수 있어야 하는 행동을 한 문장으로 씁니다. 완료 조건은 실제로 확인할 수 있는 행동이나 산출물로 표현합니다.
3. 이미 결정된 사항과 지금 필요한 가정을 구분합니다. 쉽게 되돌릴 수 있는 결정은 근거를 적고 진행합니다. 선택에 따라 공개 범위나 비용이 달라지거나 원본을 덮어쓰게 되면 그 결정부터 확인합니다.
4. 처음부터 끝까지 경험할 수 있는 작은 범위를 먼저 정하고, 어떤 화면이나 파일에서 완료 조건을 확인할지 연결합니다.

예를 들어 문의 양식을 줄이는 작업이라면 “모바일에서 필수 정보만 넣고 제출 성공을 확인할 수 있다”처럼 완료 조건을 씁니다. 기존에 받은 문의와 필수 동의 항목은 변경 범위를 정할 때 먼저 확인합니다.
